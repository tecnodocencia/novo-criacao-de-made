Em 2026-09-24 o tour guiado (criado em [[sessao_2026-09-23_tour_interativo]], slideshow de 13 cenas recriadas) foi substituído por um tour **interativo de verdade**: o professor joga uma partida de teste real (mesmo fluxo de `testGameFromCreator()`) enquanto um painel flutuante não-bloqueante guia passo a passo, só avançando quando a ação real acontece.

**Arquitetura nova:**
- `js/core/gameTour.js` (reescrito, v=4) — `TOUR_STEPS` (10 passos, não mais 13 cenas) com `{id, caption, spotlight, button}`. `spotlight` é um seletor CSS de elemento REAL (nunca clone); `button` é o rótulo do botão manual do painel coach, ou `null` para passos que avançam sozinhos via `_gameTourCheckpoint(eventName)`. Passo a passo: `welcome` (botão "Vamos lá" → dispara `persistEditorFields()` + `testGameFromCreator()` de verdade) → `difficulty` (spotlight `#modal-difficulty > div`, aguarda `difficulty-chosen`) → `bank` (spotlight `#play-item-bank`, aguarda `guess-changed` com 1ª carta) → `guess-area` (spotlight `#play-drop-slots`, aguarda todos os slots preenchidos) → `validate` (spotlight `#btn-validate`, aguarda `guess-validated`) → `result-pins` (spotlight na linha mais recente do histórico, botão "Entendi") → `nem-toda-carta` (informativo, botão) → `waiting` (passivo, sem spotlight/botão, aguarda `solution-opened`) → `solution` (spotlight `#solution-other-correct-section`, botão "Entendi" ou fechar o modal real via `solution-closed`) → `restart` (spotlight `#btn-restart-game`, botão final "Concluir Tour" que chama `closeGameTour()`).
- `state.gameTourActive` (novo campo em `js/core/state.js`) é a flag que `_gameTourCheckpoint` verifica antes de fazer qualquer coisa — é NO-OP silencioso quando `false`, então os ganchos abaixo não têm nenhum efeito/custo fora do tour.
- Ganchos de uma linha (`this._gameTourCheckpoint('evento')`) adicionados no fim de: `startGameWithDifficulty` (só dentro do branch `isTestingFromCreator`, evento `difficulty-chosen`), `renderCurrentGuess` (`guess-changed`, cobre clique E drag-drop porque ambos os fluxos já convergiam nessa função), `validateGuess` (`guess-validated`, logo após `updateAttemptCounter()` e ANTES do check de vitória/derrota), `openSolutionModal` (`solution-opened`, força avanço até o passo `solution` mesmo se o jogador vencer/perder na 1ª tentativa, pulando os passos informativos manuais), `closeSolutionModal` (`solution-closed`, não estava na lista original de 5 funções do pedido mas foi necessário para "avança com Entendi OU ao fechar o modal"), `askRestart` (`restart-requested`, hoje sem `case` correspondente no switch — gancho reservado, documentado como tal).
- `js/core/dashboard.js` `backFromPlayer()` ganhou uma guarda defensiva no topo: `if (this.state.gameTourActive) this.closeGameTour();` — evita o painel coach ficar "preso" flutuando sobre o editor se o professor usar o botão real "Voltar" em vez de "Sair do tour"/"Concluir Tour". Não fazia parte da lista literal de ganchos pedida, mas é puramente defensivo (edge case explícito do meu papel de guardião).
- `index.html` — `#modal-game-tour` (modal cheio, com backdrop bloqueante) foi substituído por `#tour-coach-panel` (fixed bottom, `pointer-events-none` no wrapper / `pointer-events-auto` no card interno, `z-[10010]` — acima de todos os modais reais como `#modal-difficulty`/`#modal-solution`, que são z-50). Nova classe CSS `.game-tour-spotlight` (outline azul + `box-shadow` pulsante via `@keyframes game-tour-pulse`) adicionada perto do fim do `<style>` do `<head>`. `partials/games/codigo-secreto/player.html` ganhou `id="btn-restart-game"` no botão real "Reiniciar" (só isso — nenhum outro id/classe pré-existente foi tocado) para o spotlight do último passo ter um alvo estável.
- Métodos REMOVIDOS (não existem mais): `gameTourNext`, `gameTourPrev`, `gameTourGoTo` (navegação livre "Próximo/Voltar" da versão slideshow — incompatível com o novo modelo de avanço por ação real). Método novo: `gameTourContinue()` (botão único do painel, comportamento varia por passo).
- `partials/core/modals.html` continua morto (nunca injetado — `core-modals-mount` não existe no DOM real) e ainda contém a versão ANTIGA (13 cenas) do `#modal-game-tour`/ids relacionados — não foi tocado nesta sessão por instrução explícita do usuário; grep por `tour-scene`/`modal-game-tour`/`gameTourNext` só retorna esse arquivo morto e a nota de memória da sessão anterior, nada vivo.

**Cascata de versões `?v=N` desta sessão:** `player.js` v9→v10 (referenciado só em `index.js`) → `index.js` (codigo-secreto) v5→v6 e `gameTour.js` v3→v4 e `dashboard.js` v9→v10 (todos referenciados só em `app.js`) → `index.html` `js/app.js?v=10`→`?v=11`.
